# garmoniya-booking2
# Проект «Гармония» — Сервис бронирования отелей

Многостраничный веб-сайт для поиска и бронирования жилья. Проект включает интерактивные элементы, работу с картами и продуманную навигацию.

[Посмотреть Live Demo] — **[[().](https://share.google/VXfYHrV0caHJbCfR5)](https://share.google/VXfYHrV0caHJbCfR5)**

---

## 🚀 Функционал и страницы

Проект разделен на логические модули для удобства пользователя:

- **index.html** — Главная страница: презентация проекта и основные предложения.
- **broner.html** — Модуль бронирования: содержит **интерактивную 3D-карту** с домиками и индикаторами состояния.
- **about.html** — О нас: подробная информация о сервисе и миссии проекта.
- **novo.html** — Новости и график: информация о времени открытия и актуальных событиях.
- **contackt.html** — Контакты: форма обратной связи и детальная контактная информация.

## 🛠 Технологический стек

- **HTML5:** Семантическая верстка нескольких страниц.
- **CSS3:** Кастомные стили, адаптивность под мобильные устройства.
- **JavaScript:** Реализация интерактивности (3D-карта, индикаторы на странице бронирования).
- **Инструменты:** Visual Studio Code, Git.

## 📂 Структура файлов

- `/*.html` — основные страницы сайта.
- `/css/` — папка со стилями оформления.
- `/js/` — логика работы 3D-карты и интерактивных элементов.
- `/img/` — графические ресурсы и медиа-файлы.

## ⚙️ Как запустить проект локально

Так как проект выполнен на чистом стеке (HTML/CSS/JS), установка дополнительных зависимостей не требуется:

1. Склонируйте репозиторий:
   ```bash
   git clone [(https://github.com/goose112/garmoniya-booking2.git)]
   ```
2. Откройте файл `index.html` в любом современном браузере.
   *Рекомендуется использовать расширение **Live Server** в VS Code для корректной работы путей.*
