# Проект «Гармония» — Сервис бронирования отелей

Веб-приложение для поиска и бронирования отелей, разработанное на React. Проект демонстрирует навыки создания современных интерфейсов, работы с состоянием приложения и адаптивной верстки.

[Посмотреть Live Demo] — **(https://cx878558.tw1.ru/index.html)**

---

## 🚀 Основной функционал

- **Главная страница (`index.html` в сборке):** Презентация лучших предложений и удобная навигация.
- **Поиск и фильтрация:** Реализована логика выбора отелей по параметрам.
- **Адаптивный дизайн:** Интерфейс корректно отображается на смартфонах, планшетах и десктопах.
- **Интерактивность:** Использование современных возможностей React для плавного пользовательского опыта без перезагрузки страниц.

## 🛠 Технологический стек

- **Core:** React.js
- **Стилизация:** CSS3 (модульная структура), Flexbox, Grid
- **Инструменты:** Git, Visual Studio Code, NPM

## 📂 Структура проекта

- `public/index.html` — главная точка входа.
- `src/components/` — переиспользуемые React-компоненты.
- `src/styles/` — файлы стилей (CSS), разделенные по логике.
- `src/App.js` — основная логика маршрутизации и структуры приложения.

## ⚙️ Как запустить проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone [ССЫЛКА_НА_ТВОЙ_РЕПОЗИТОРИЙ]
   ```
2. Перейдите в папку проекта:
   ```bash
   cd harmony
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите проект:
   ```bash
   npm start
   ```
